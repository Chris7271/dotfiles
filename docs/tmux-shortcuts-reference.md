# tmux 快捷键速查表

> 基于增强配置的完整快捷键参考

## 图例

- `Ctrl+b` = 前缀键（默认）
- 🔥 = 新增/增强快捷键
- ⚡ = 无需前缀键（直接按）

## 🎯 最常用快捷键（必记）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+b \|` | 垂直分割 🔥 | 左右分屏 |
| `Ctrl+b -` | 水平分割 🔥 | 上下分屏 |
| `Alt+方向键` | 切换窗格 ⚡🔥 | 无需前缀键 |
| `Alt+数字` | 跳转窗口 ⚡🔥 | 如 Alt+1 跳到窗口1 |
| `Shift+←/→` | 切换窗口 ⚡🔥 | 无需前缀键 |
| `Ctrl+b f` | 全屏窗格 🔥 | 专注模式 |
| `Ctrl+b d` | 断开会话 | 后台运行 |
| `Ctrl+b c` | 新建窗口 | 保持当前目录 |

## 📋 会话管理

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Ctrl+b s` | 查看所有会话 | 列表选择 |
| `Ctrl+b d` | 自动保存 + 断开 🔥 | 断开前自动保存会话状态 |
| `Ctrl+b D` | 选择要断开的会话 | 多客户端时有用 |
| `Ctrl+b (` | 上一个会话 | 快速切换 |
| `Ctrl+b )` | 下一个会话 | 快速切换 |
| `Ctrl+b b` | 最近使用的会话 🔥 | 两个会话间切换 |
| `Ctrl+b N` | 创建新会话 🔥 | 提示输入名称 |
| `Ctrl+b $` | 重命名当前会话 | 输入新名称 |
| `Ctrl+b Ctrl+s` | 保存会话 🔥 | tmux-resurrect 手动保存 |
| `Ctrl+b Ctrl+r` | 恢复会话 🔥 | tmux-resurrect 手动恢复 |

**命令行操作**：
```bash
tmux new -s work          # 创建会话
tmux ls                   # 列出会话
tmux attach -t work       # 连接会话
tmux kill-session -t work # 删除会话
```

**Shell 别名**（macOS 配置在 `~/.zshrc`，Linux 配置在 `~/.bashrc`）：
```bash
tn work                   # = tmux new -s work
tl                        # = tmux ls
ta                        # = tmux attach（连接最近的会话）
tat work                  # = tmux attach -t work（连接指定会话）
tk work                   # = tmux kill-session -t work
```

| 快捷键 | 功能 | 说明 |

| `Ctrl+b P` | 选择粘贴缓冲区 🔥 | 查看历史复制 |

**系统剪贴板支持**：

`y` 键复制到系统剪贴板的方式因平台而异（已在配置中自动检测）：

| 平台 | 剪贴板工具 | 粘贴方式 |
|------|-----------|---------|
| macOS | pbcopy（系统自带） | `Cmd+V` |
| Linux | xclip（需安装） | `Ctrl+Shift+V` |

```bash
# Linux 需要安装 xclip
sudo apt install xclip
Ctrl+b r                        # 重载 tmux 配置使其生效
```

**两种复制方式对比**：

| 方式 | 操作 | 说明 |
|------|------|------|
| 鼠标 | `Shift+鼠标拖选` → `Ctrl+Shift+C` | 简单快捷，适合少量文本 |
| 键盘 | `Ctrl+b [` → `v` 选择 → `y` 复制 | Vim 风格，支持搜索定位 |

## 🎨 实用场景

### 场景 1: 快速开发环境

```
1. Alt+1        # 跳到窗口1（编辑器）
2. Alt+2        # 跳到窗口2（服务器）
3. Alt+3        # 跳到窗口3（Git）
4. Alt+方向键    # 窗格间快速切换
```

### 场景 2: 代码编写与预览

```
1. Ctrl+b |     # 垂直分割
2. Alt+→        # 切换到右边窗格
3. glow -p README.md   # 预览 Markdown
4. Alt+←        # 回到编辑器
5. Ctrl+b f     # 需要时全屏
```

### 场景 3: 多服务器监控

```
1. Ctrl+b e     # 创建三分割布局
2. Ctrl+b S     # 开启窗格同步
3. ssh server1  # 所有窗格同时执行
4. top          # 所有窗格同时运行
5. Ctrl+b S     # 关闭同步
```

### 场景 4: 调试与日志

```
1. Ctrl+b |     # 分割窗格
2. Alt+→        # 右边窗格
3. tail -f log  # 查看日志
4. Ctrl+b P     # 开启日志记录（可选）
5. Alt+←        # 回到主窗格
```

## 💡 使用技巧

### 1. 窗口快速跳转

使用 `Alt+数字` 是最快的窗口切换方式：
```
Alt+1  编辑器
Alt+2  服务器
Alt+3  Git
Alt+4  测试
Alt+5  监控
```

### 2. 窗格高效切换

优先使用 `Alt+方向键`，无需前缀键：
```
Alt+→  右边窗格
Alt+←  左边窗格
Alt+↑  上面窗格
Alt+↓  下面窗格
```

### 3. 快速调整布局

```
Ctrl+b f    # 需要专注时，全屏当前窗格
Ctrl+b =    # 需要平等查看时，平铺所有窗格
Ctrl+b +    # 垂直排列，适合多任务
```

### 4. 复制工作流

**键盘方式（推荐）**：
```
1. Ctrl+b [          # 进入复制模式
2. /搜索关键词        # 搜索定位到目标内容
3. v                 # 开始选择
4. hjkl 或方向键      # 扩展选区
5. y                 # 复制（需 xclip 才能到系统剪贴板）
6. Ctrl+Shift+V      # 在任何程序中粘贴
```

**鼠标方式**：
```
1. Shift+鼠标拖选     # 选择文本
2. Ctrl+Shift+C      # 复制到系统剪贴板
3. Ctrl+Shift+V      # 粘贴到任何程序
```

> **重要**：首次安装 xclip 后记得按 `Ctrl+b r` 重载配置。

### 5. 会话管理最佳实践

```
# 每天工作开始
ta                       # 快速连接到最近的会话
# 或连接指定会话
tat work || tn work      # 连接或新建会话

# 工作中
Alt+1, Alt+2, Alt+3     # 快速切换窗口
Ctrl+b Ctrl+s            # 随时手动保存会话（自动每15分钟保存）

# 离开
Ctrl+b d                 # 自动保存 + 断开会话

# 回来
ta                       # 快速连接到最近的会话

# 重启后恢复
ta                       # tmux 启动时自动恢复，直接连接即可

# 查看有哪些会话
tl                       # 列出所有会话
```

## 🍎 macOS Terminal.app 配置

macOS Terminal.app 需要额外配置才能使用 `Alt+数字` 和 `Alt+方向键` 快捷键。

### 开启 Option 作为 Meta 键

**Terminal** → **Settings** (`Cmd+,`) → **Profiles** → **Keyboard** → 勾选 **"Use Option as Meta key"**

### 配置 Option+方向键

开启 Meta 键后，`Alt+数字` 可以正常使用，但 `Alt+方向键` 仍需手动配置。在同一个 Keyboard 页面点 **+** 添加：

| 按键 | Action | 输入内容 |
|---|---|---|
| `⌥←` | Send Text | 按 `Esc`，输入 `[1;3D` |
| `⌥→` | Send Text | 按 `Esc`，输入 `[1;3C` |
| `⌥↑` | Send Text | 按 `Esc`，输入 `[1;3A` |
| `⌥↓` | Send Text | 按 `Esc`，输入 `[1;3B` |

> 输入框中先按 **Esc** 键（显示 `\033`），再输入后面的字符。

配置完成后即可使用 `Alt+方向键` 切换窗格。Linux 用户无需此配置。
